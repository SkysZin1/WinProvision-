# 0.7.0 release notes

Version 0.7.0 adds the applications and installation improvements below. Full Windows installation testing remains pending.

| Application | Category | WinGet ID |
| --- | --- | --- |
| Opera GX | Browsers / Navegadores | Opera.OperaGX |
| Zoom | Communication / Comunicação | Zoom.Zoom |
| qBittorrent | Utilities / Utilitários | qBittorrent.qBittorrent |
| Blender | Design & 3D / Design e 3D | BlenderFoundation.Blender |
| WizTree | Utilities / Utilitários | AntibodySoftware.WizTree |
| Cursor | Development / Desenvolvimento | Anysphere.Cursor |

All six use the existing exact-ID WinGet installation flow and are available both before installation in the Builder and after first boot. None is preselected. Descriptions are available in English and Brazilian Portuguese; icons are bundled generic vector symbols.

Package IDs were checked against Microsoft's [WinGet manifest repository](https://github.com/microsoft/winget-pkgs/tree/master/manifests). Package versions, hardware requirements and license terms follow the publishers.

The App Picker now shows completed, failed and deferred apps after an installation attempt. Retry failures only queues failed IDs; completed apps are retained in the summary. Saved results remain available when reopening the picker.

Before installing, the background worker checks HTTPS connectivity against Microsoft's connectivity endpoint (15-second request timeout). When required by the selected apps, it also verifies App Installer availability and probes WinGet with a 15-second process timeout. Failures provide connection or Microsoft Store recovery guidance. Each retry repeats these checks. Networks that block the connectivity endpoint can prevent this check from passing even when other sites work; a successful check cannot guarantee every publisher's download will succeed.

Validation: 272 Builder/XML checks, successful compilation without warnings, bilingual WPF category/search/selection/summary tests, and 14 mocked worker scenarios in each language covering connectivity, App Installer failures, cancellation and retries. These checks do not download or install the applications; actual installation remains to be tested.
